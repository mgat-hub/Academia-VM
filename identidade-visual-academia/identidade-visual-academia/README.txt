LIMITAÇÕES
- O cartaz é um JPEG de 1000 px de largura (comprimido pelo WhatsApp). Os recortes são pequenos: a foto das crianças (785x438) não serve de imagem de topo em ecrã largo.

- Os HEX são medidos no JPEG e podem diferir do original.
